## 🚀 نصب

### روش 1: نصب دستی (توصیه می‌شود)

1. **دانلود افزونه**
   ```bash
   # اگر از Git استفاده می‌کنید
   cd wp-content/plugins/
   git clone https://github.com/rez4156684-bot/payamakhotel.git
   ```

2. **کپی فایل‌ها**
   - پوشه `hotel-booking-widget-elementor` را در مسیر `wp-content/plugins/` قرار دهید

3. **فعال‌سازی**
   - به پنل مدیریت WordPress بروید
   - از منوی **افزونه‌ها** → **افزونه‌های نصب شده**
   - افزونه **Hotel Booking Widget for Elementor** را فعال کنید

### روش 2: آپلود از پنل مدیریت

1. پوشه افزونه را به صورت ZIP فشرده کنید
2. به **افزونه‌ها** → **افزودن** بروید
3. روی **بارگذاری افزونه** کلیک کنید
4. فایل ZIP را انتخاب و نصب کنید
5. افزونه را فعال کنید

## ⚙️ راه‌اندازی

### مرحله 1: بررسی وضعیت

پس از فعال‌سازی، به مسیر زیر بروید:
```
ووکامرس → Hotel Widget
```

در این صفحه وضعیت سیستم را بررسی کنید:
- ✅ Elementor فعال است
- ✅ WooCommerce فعال است
- ✅ افزونه نصب شده است

### مرحله 2: ایجاد محصول هتل

1. به **محصولات** → **افزودن** بروید
2. اطلاعات هتل/اتاق را وارد کنید:
   - نام محصول (مثلاً "اتاق دو تخته استاندارد")
   - قیمت (قیمت هر شب)
   - توضیحات کوتاه
   - تصویر شاخص
   - گالری تصاویر

3. محصول را منتشر کنید

### مرحله 3: استفاده در Elementor

1. صفحه یا قالب خود را با Elementor ویرایش کنید
2. از قسمت جستجو، "رزرو هتل" را جستجو کنید
3. ویجیت را به صفحه اضافه کنید
4. محصول هتل را از کشویی انتخاب کنید

## 🎨 سفارشی‌سازی

### افزودن امکانات سفارشی

می‌توانید لیست امکانات پیش‌فرض را در فایل زیر ویرایش کنید:
```php
wp-content/plugins/hotel-booking-widget-elementor/widgets/hotel-booking-widget.php
```

در خط ~229، آرایه `$default_amenities` را ویرایش کنید:
```php
$default_amenities = array(
    array('icon' => '📶', 'text' => 'وای‌فای رایگان'),
    array('icon' => '❄️', 'text' => 'تهویه مطبوع'),
    // امکانات بیشتر...
);
```

### سفارشی‌سازی CSS

برای تغییرات CSS سفارشی، می‌توانید در تنظیمات قالب یا در Customizer کدهای زیر را اضافه کنید:

```css
/* تغییر رنگ اصلی */
:root {
    --hbw-primary: #ff6600 !important;
}

/* تغییر فونت */
.hbw-title {
    font-family: 'Your Custom Font', sans-serif;
}
```

### سفارشی‌سازی JavaScript

برای رفتارهای سفارشی:

```javascript
jQuery(document).ready(function($) {
    // دسترسی به کلاس ویجیت
    $('.hbw-hotel-card').each(function() {
        const widget = $(this).data('widget-instance');
        // کدهای سفارشی شما
    });
});
```

## ❓ سوالات متداول

### چگونه قیمت را بر اساس تعداد مهمان تغییر دهم؟

در حال حاضر، قیمت بر اساس تعداد شب‌ها محاسبه می‌شود. برای محاسبه بر اساس مهمان، می‌توانید کد JavaScript را در فایل `hotel-booking-widget.js` ویرایش کنید:

```javascript
calculateBooking() {
    // کد فعلی...

    // اضافه کردن محاسبه بر اساس مهمان
    const adults = parseInt(this.$element.find('[name="adults"]').val());
    const children = parseInt(this.$element.find('[name="children"]').val());

    // فرمول سفارشی شما
    const guestMultiplier = adults + (children * 0.5);
    const totalPrice = nights * this.pricePerNight * guestMultiplier;
}
```

### چگونه تقویم میلادی استفاده کنم؟

در فایل `hotel-booking-widget.js` خط ~54:
```javascript
const baseConfig = {
    locale: 'en', // تغییر از 'fa' به 'en'
    dateFormat: 'Y-m-d',
    // ...
};
```

### چگونه امکانات را از متافیلد محصول بخوانم؟

در فایل `hotel-booking-widget.php`، متد `render_hotel_card` را ویرایش کنید:

```php
// خواندن امکانات از متافیلد
$custom_amenities = get_post_meta($product_id, '_hotel_amenities', true);

if (!empty($custom_amenities)) {
    foreach ($custom_amenities as $amenity) {
        // نمایش امکانات سفارشی
    }
}
```

### چگونه ویجیت را در صفحه محصول پیش‌فرض قرار دهم؟

1. به **Elementor** → **Theme Builder** بروید
2. یک قالب **Single Product** جدید بسازید
3. ویجیت را در جای دلخواه قرار دهید
4. شرایط نمایش را تنظیم کنید (فقط محصولات هتل)

## 🔧 عیب‌یابی

### تقویم نمایش داده نمی‌شود

**علت**: کتابخانه Flatpickr بارگذاری نشده

**راه‌حل**:
```php
// در فایل functions.php قالب
add_action('wp_enqueue_scripts', function() {
    wp_enqueue_script('flatpickr-script');
    wp_enqueue_style('flatpickr-style');
}, 99);
```

### استایل‌ها درست نمایش داده نمی‌شوند

**علت**: تداخل CSS با قالب

**راه‌حل**:
```php
// پاک کردن کش
// در پنل مدیریت: ابزارها → Site Health → Clear Cache
```

یا استفاده از `!important` در CSS سفارشی

### قیمت محاسبه نمی‌شود

**علت**: قیمت محصول درست تنظیم نشده

**راه‌حل**:
1. محصول را ویرایش کنید
2. در بخش **قیمت عادی** عددی وارد کنید
3. محصول را ذخیره کنید

### ویجیت در Elementor نمایش داده نمی‌شود

**بررسی‌ها**:
```
1. افزونه فعال است؟
2. Elementor نسخه 3.0+ است؟
3. کش Elementor پاک شده؟
```

**راه‌حل**:
```
Elementor → Tools → Regenerate CSS → Regenerate Files
```
