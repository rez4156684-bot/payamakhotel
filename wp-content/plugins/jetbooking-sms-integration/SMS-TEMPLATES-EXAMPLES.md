# نمونه الگوهای پیامکی برای رزرو هتل

این فایل شامل نمونه‌های مختلفی از الگوهای پیامکی است که می‌توانید برای سایت رزرو هتل خود استفاده کنید.

## 📱 الگوی پیامک برای مشتری - تأیید سفارش

```
مشتری گرامی {billing_first_name}

رزرو شما با موفقیت ثبت شد ✅

{booking_info}

شماره سفارش: #{order_number}
مبلغ قابل پرداخت: {order_total}

با تشکر از انتخاب شما
{site_title}
```

```

{site_title}
```

## 📱 الگوی پیامک برای مدیر - سفارش جدید

```

مشتری: {billing_first_name} {billing_last_name}
موبایل: {billing_phone}

{booking_info}

مبلغ: {order_total}
وضعیت: {order_status}

مدیریت سفارش:
{site_url}/wp-admin/post.php?post={order_id}&action=edit
```

## 🎨 نکات طراحی پیامک

### 1. استفاده از ایموجی
ایموجی‌ها پیامک را جذاب‌تر می‌کنند:
- 🏨 برای هتل
- 🛏️ برای اتاق
- 📅 برای تاریخ
- 🌙 برای شب
- ✅ برای تأیید
- 💰 برای مبلغ
- 📞 برای تماس

### 2. طول پیامک
- هر پیامک فارسی: حداکثر 70 کاراکتر (1 پیامک)
- بیشتر از 70 کاراکتر: چند قسمتی می‌شود
- سعی کنید پیامک را کوتاه و مفید نگه دارید

### 3. اطلاعات ضروری
حتماً در پیامک قرار دهید:
- نام هتل و اتاق
- تاریخ ورود و خروج
- شماره سفارش
- راه ارتباطی (تلفن یا سایت)

### 4. زمان‌بندی ارسال
- تأیید سفارش: بلافاصله
- تأیید پرداخت: بلافاصله
- یادآوری: 1 روز قبل از ورود
- تشکر: بعد از خروج

## 🔧 نحوه استفاده

1. یکی از الگوهای بالا را انتخاب کنید
2. آن را در تنظیمات افزونه پیامکی خود کپی کنید
3. در صورت نیاز، متن را ویرایش کنید
4. ذخیره و تست کنید

## ⚠️ نکات مهم

- همه متغیرها باید دقیقاً مطابق نمونه نوشته شوند
- حتماً با یک سفارش تستی، پیامک را آزمایش کنید
- اگر متغیری کار نمی‌کند، از متغیر `{booking_info}` استفاده کنید که همه اطلاعات را نشان می‌دهد

## 📋 لیست کامل متغیرهای JetBooking

متغیرهای اختصاصی این افزونه:
- `{hotel_name}` - نام هتل
- `{room_name}` - نام اتاق
- `{checkin_date}` - تاریخ ورود
- `{checkout_date}` - تاریخ خروج
- `{nights}` - تعداد شب
- `{booking_info}` - اطلاعات کامل (شامل همه موارد بالا)

متغیرهای استاندارد ووکامرس:
- `{order_number}` - شماره سفارش
- `{order_total}` - مبلغ کل
- `{order_status}` - وضعیت سفارش
- `{billing_first_name}` - نام
- `{billing_last_name}` - نام خانوادگی
- `{billing_phone}` - شماره تلفن
- `{site_title}` - نام سایت
- `{site_url}` - آدرس سایت

---

**توجه:** این الگوها قابل سفارشی‌سازی هستند. می‌توانید آن‌ها را با توجه به نیاز کسب‌وکار خود تغییر دهید.
