# JetBooking SMS Integration

یکپارچه‌سازی اطلاعات رزرو JetBooking با پیامک‌های ووکامرس

## نصب سریع

1. این پوشه را در دایرکتوری `/wp-content/plugins/` کپی کنید
2. از پنل مدیریت وردپرس، افزونه را فعال کنید
3. از متغیرهای زیر در الگوهای پیامک استفاده کنید

## متغیرهای موجود

- `{hotel_name}` - نام هتل
- `{room_name}` - نام اتاق
- `{checkin_date}` - تاریخ ورود
- `{checkout_date}` - تاریخ خروج
- `{nights}` - تعداد شب
- `{booking_info}` - اطلاعات کامل رزرو

## مثال استفاده

```
مشتری گرامی، رزرو شما ثبت شد:

{booking_info}

شماره سفارش: {order_number}
مبلغ: {order_total}
```

برای اطلاعات بیشتر، فایل README.md در ریشه پروژه را مطالعه کنید.
