# افزونه یکپارچه‌سازی JetBooking با پیامک‌های ووکامرس

## 📋 توضیحات

این افزونه مشکل نمایش اطلاعات رزرو هتل در پیامک‌های ووکامرس را حل می‌کند. با استفاده از این افزونه، اطلاعات کامل رزرو شامل نام هتل، نام اتاق، تاریخ ورود و خروج به صورت خودکار به پیامک‌های ارسالی به کاربر و مدیر اضافه می‌شود.

## ✨ ویژگی‌ها

- ✅ استخراج خودکار اطلاعات رزرو از JetBooking
- ✅ نمایش نام هتل در پیامک
- ✅ نمایش نام اتاق در پیامک
- ✅ نمایش تاریخ ورود و خروج
- ✅ محاسبه و نمایش تعداد شب اقامت
- ✅ سازگار با افزونه‌های پیامکی مختلف:
  - WooCommerce SMS
  - Persian WooCommerce SMS
  - Digits
  - YITH WooCommerce SMS Notifications
  - و سایر افزونه‌های پیامکی ووکامرس
- ✅ پشتیبانی از تقویم شمسی (در صورت وجود افزونه Parsidate)
- ✅ متغیرهای سفارشی برای الگوهای پیامکی

## 📦 پیش‌نیازها

- WordPress 5.0 یا بالاتر
- WooCommerce 4.0 یا بالاتر
- PHP 7.2 یا بالاتر
- JetBooking (افزونه Elementor)
- یک افزونه پیامکی ووکامرس (اختیاری)

## 🚀 نصب

### روش 1: آپلود مستقیم در وردپرس

1. پوشه `wp-content/plugins/jetbooking-sms-integration` را به دایرکتوری `/wp-content/plugins/` سایت خود کپی کنید
2. وارد پنل مدیریت وردپرس شوید
3. به بخش **افزونه‌ها** بروید
4. افزونه **JetBooking SMS Integration** را پیدا کرده و آن را فعال کنید

### روش 2: آپلود فایل ZIP

1. کل پوشه `wp-content/plugins/jetbooking-sms-integration` را فشرده (ZIP) کنید
2. وارد پنل مدیریت وردپرس شوید
3. به **افزونه‌ها > افزودن** بروید
4. روی **بارگذاری افزونه** کلیک کنید
5. فایل ZIP را انتخاب و آپلود کنید
6. افزونه را فعال کنید

## 🔧 پیکربندی

### پیکربندی پیامک‌ها

پس از نصب و فعال‌سازی، می‌توانید از متغیرهای زیر در الگوهای پیامکی خود استفاده کنید:

#### متغیرهای موجود:

- `{hotel_name}` - نام هتل
- `{room_name}` - نام اتاق
- `{checkin_date}` - تاریخ ورود
- `{checkout_date}` - تاریخ خروج
- `{nights}` - تعداد شب اقامت
- `{booking_info}` - اطلاعات کامل رزرو (شامل همه موارد بالا)

#### مثال الگوی پیامک:

```
سفارش #{order_number} ثبت شد

{booking_info}

مبلغ: {order_total}
با تشکر از خرید شما
```

**خروجی پیامک:**

```
سفارش #1234 ثبت شد

هتل: هتل پارسیان آزادی
اتاق: اتاق دو تخته VIP
ورود: 1403/08/15
خروج: 1403/08/18
تعداد شب: 3

مبلغ: 15,000,000 تومان
با تشکر از خرید شما
```

### پیکربندی برای افزونه‌های پیامکی مختلف

#### 1. افزونه Persian WooCommerce SMS

1. به **ووکامرس > تنظیمات > پیامک** بروید
2. در قسمت الگوی پیامک، از متغیرهای فوق استفاده کنید

#### 2. افزونه WooCommerce SMS

1. به تنظیمات افزونه پیامکی بروید
2. در قسمت Message Template، متغیرهای فوق را اضافه کنید

#### 3. افزونه Digits

1. به **تنظیمات > Digits** بروید
2. در بخش WooCommerce SMS، از متغیرهای فوق استفاده کنید

## 💡 نحوه کار

افزونه به صورت خودکار:

1. **در هنگام ثبت سفارش:**
   - اطلاعات رزرو را از آیتم‌های سفارش استخراج می‌کند
   - این اطلاعات را در متادیتای سفارش ذخیره می‌کند

2. **در هنگام ارسال پیامک:**
   - اطلاعات رزرو را از سفارش دریافت می‌کند
   - متغیرهای سفارشی را جایگزین می‌کند
   - اگر پیامک فقط شامل کلمه "رزرو" باشد، آن را با اطلاعات کامل جایگزین می‌کند

## 🔍 رفع مشکلات

### پیامک‌ها همچنان اطلاعات رزرو را نشان نمی‌دهند

**راه حل 1:** بررسی فعال بودن افزونه
- مطمئن شوید افزونه JetBooking SMS Integration فعال است

**راه حل 2:** پاک کردن کش
- کش وردپرس و افزونه کش را پاک کنید

**راه حل 3:** بررسی الگوی پیامک
- مطمئن شوید در الگوی پیامک از متغیرهای صحیح استفاده کرده‌اید
- یا اگر الگوی خاصی ندارید، افزونه به صورت خودکار اطلاعات را اضافه می‌کند

**راه حل 4:** ثبت سفارش جدید
- یک سفارش جدید ثبت کنید (سفارش‌های قدیمی ممکن است اطلاعات رزرو را نداشته باشند)

### اطلاعات رزرو ناقص است

**بررسی کنید:**
- محصولات به درستی به عنوان رزرو JetBooking تنظیم شده باشند
- فیلدهای مورد نیاز در فرم رزرو پر شده باشند

## 🛠️ توسعه‌دهندگان

### هوک‌ها و فیلترهای موجود

```php
// تغییر فرمت نمایش اطلاعات رزرو
add_filter('jetbooking_sms_booking_info_format', function($info, $booking_details) {
    // فرمت سفارشی خود را ایجاد کنید
    return $info;
}, 10, 2);

// تغییر فرمت تاریخ
add_filter('jetbooking_sms_date_format', function($format) {
    return 'Y-m-d'; // فرمت دلخواه
}, 10, 1);
```

### ساختار فایل‌ها

```

└── languages/                         # فایل‌های ترجمه (در آینده)
```
